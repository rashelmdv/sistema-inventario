# Sistema de Control de Inventario

Este repositorio contiene la configuración inicial y la estructura base para el desarrollo del Sistema de Control de Inventario.

## Funcionalidades
- Registrar productos.
- Consultar productos.
- Modificar información de productos.
- Eliminar productos.
- Consultar existencias.
- Registrar entradas y salidas de productos.
- Generar un reporte básico de inventario.

## Estructura del Proyecto
- `src/`: Código fuente.
- `tests/`: Pruebas.
- `docs/`: Documentación técnica.
- `.github/workflows/`: CI/CD.

## Tecnologías
- Git + GitHub
- JavaScript (Node.js)
- Markdown
